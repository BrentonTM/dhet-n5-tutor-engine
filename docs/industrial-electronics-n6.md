# Industrial Electronics N6

Choose **Study path → N6 → Industrial Electronics** in either the Instrumentation
or Heavy Current programme. Open **Tutor & lab → Lessons** for the nine modules,
or **Flashcards** to revise one module at a time. The Practice and Mock exam tabs
use original Trentox questions with worked marking guides.

The study map follows DHET subject code 8080186. The Formula hub links to the
syllabus and to the January 2026 Report 191 ICASS guidelines, which cover
assessment across Engineering Studies. The 2020 ICASS attachment is an archive.

The original module PDFs and archived guide stay in the Desktop `attachments`
folder. When running Trentox on this computer with
`python -m streamlit run app.py --server.address 127.0.0.1`, open the local PDF
under the matching lesson or under ICASS in the Formula hub. The app does not
read these attachments when deployed publicly or send them to Tex.
