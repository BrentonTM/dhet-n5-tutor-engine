# Sign-in symbols

Google: https://www.gstatic.com/firebasejs/ui/2.0.0/images/auth/google.svg

Apple: Simple Icons (CC0), https://github.com/simple-icons/simple-icons/blob/develop/icons/apple.svg.
White fill is used on Trentox's dark sign-in page.

Microsoft: four-square brand mark drawn as local SVG geometry using the standard
Microsoft symbol colours. Provider names identify their respective sign-in services.

These local assets avoid loading third-party images before a student chooses a provider.
